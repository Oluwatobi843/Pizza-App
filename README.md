# Pizza App

> A React-based pizza ordering interface demonstrating component-driven frontend development, client-side state and interactive user flows.

## Overview

Pizza App is a frontend application focused on an interactive pizza-ordering experience. It demonstrates how reusable React components, application state and user events can be combined to create a responsive product interface.

## Key features

- Interactive pizza selection and ordering flows
- Reusable React components
- Client-side state management
- User event handling
- Responsive UI
- Frontend testing setup

## Technology stack

- React 18
- JavaScript / JSX
- React DOM
- React Testing Library
- Jest DOM
- User Event

## Architecture

```text
User interaction
       |
       v
React Components
       |
       v
Application State
       |
       v
Order / Selection Logic
       |
       v
Rendered UI
```

The application keeps UI behavior component-driven, allowing individual parts of the ordering experience to be developed and tested independently.
