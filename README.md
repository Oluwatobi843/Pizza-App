# Pizza App

> A React-based pizza ordering interface demonstrating component-driven frontend development and interactive application state.

## Overview

Pizza App is a frontend project focused on creating an interactive ordering experience with reusable React components, user actions and client-side state.

## Technology Stack

- React 18
- JavaScript / JSX
- React DOM
- React Testing Library
- Jest DOM
- User Event

## Key Features

- Interactive pizza selection/order flows
- Component-based UI
- Client-side state and event handling
- Responsive application interface
- Frontend testing setup

## Architecture

```text
React Components
      |
      v
Application State
      |
      v
User Actions / Order Flow
      |
      v
Rendered UI
```

## Run locally

```bash
npm install
npm start
```

## Tests

```bash
npm test
```

## Engineering Value

Demonstrates practical React development, component composition, event handling, state-driven UI and frontend testing.
